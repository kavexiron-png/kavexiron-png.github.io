# Case Study: Bella Bistro — Modern Restaurant Website & Online Reservations

**Note:** This is a conceptual/demo project built for portfolio purposes. Bella Bistro is a
fictional restaurant; no real client engagement occurred. It demonstrates the design,
front-end, and UX approach I bring to real restaurant and hospitality bookings.

## Client / Problem
Bella Bistro, a 12-year-old Italian-Mediterranean restaurant, had no real website beyond a
Facebook page and a Yelp listing. Nearly all reservations came in by phone, tying up staff
during dinner service and losing walk-away bookings after hours when no one could answer. The
restaurant needed a modern, mobile-first site that reflected the quality of the food and let
guests browse the menu and book a table themselves, any time of day.

## Solution
I designed and built a single-page marketing site covering the full guest journey: a full-bleed
hero with clear calls-to-action, an About section telling the founders' story, a tabbed menu
(Starters / Mains / Desserts) with real pricing, an online reservation form with date/time/party
size validation and an instant client-side confirmation screen, a photo gallery, guest
testimonials, and a location/hours block with an embedded map. The design uses a warm
forest-green, burgundy, and gold palette with Playfair Display headings to read as upscale but
approachable, with sticky navigation, smooth-scroll anchors, a mobile hamburger menu, and
IntersectionObserver-driven scroll-reveal animations for polish without heavy JS.

## Tech Stack
- HTML5 + Tailwind CSS (CDN) for rapid, consistent utility styling
- Hand-written CSS for bespoke components (buttons, reveal animations, tabs, form styling)
- Vanilla JavaScript (no frameworks/build step) for nav toggle, menu tabs, scroll reveal, and
  the client-side reservation form
- Google Fonts (Playfair Display + Inter), inline SVG icons, Unsplash photography
- Fully static — deployable to GitHub Pages or any static host with zero build step

## Result (projected / illustrative)
Based on comparable restaurant-site launches, moving reservations online typically shifts
60–70% of booking volume away from phone calls within the first two months, freeing roughly
5–8 staff-hours per week during service. A mobile-optimized menu and gallery also tend to lift
average session time and direct-visit conversion by 25–35% versus a Facebook-only presence.
These figures are illustrative projections for this demo, not measured results from a real
deployment.
