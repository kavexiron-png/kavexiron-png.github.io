# Case Study: LaunchPad — SaaS Landing Page & Conversion Copywriting

**Project type:** Fictional/conceptual portfolio demo (no real client; built to demonstrate design + copywriting capability for freelance/agency pitches)

## Client & Problem

The brief: an early-stage B2B SaaS startup ("LaunchPad," a workflow-automation tool for agencies and freelance teams) needed a high-converting landing page ahead of a public launch. Their existing placeholder page had generic copy, no clear pain-point framing, and no pricing clarity — visitors couldn't tell who the product was for or why it mattered in under 5 seconds.

## Solution

Rather than list features, the page is structured around a specific, relatable pain: agencies losing billable hours to onboarding chaos, slow approvals, and lossy handoffs. Copy follows a Problem → Agitate → Solution arc section by section (explicit "Problem/Solution" block with 3 pain points mapped 1:1 to fixes), backed by a benefit-first features grid, a 3-step "how it works" flow to lower perceived setup friction, and testimonials with specific, credible metrics (e.g., "cut onboarding time by 60%," "approval time dropped from 5 days to 36 hours") rather than vague praise. Pricing includes a working Monthly/Annual toggle with a real 20% discount calculation to reduce purchase friction. Visual design uses an indigo/violet gradient system on a near-white base for a premium, trustworthy SaaS feel, with a CSS/HTML "browser mockup" dashboard in the hero instead of a real screenshot.

## Tech Stack

Static HTML5 + Tailwind CSS (CDN) + vanilla JS — no build step, no backend. Custom CSS handles gradients, the accordion/toggle animations, and scroll-reveal (IntersectionObserver). Fully responsive, mobile-first nav, deployable as-is to GitHub Pages.

## Result (conceptual)

As a demo piece, this showcases end-to-end landing-page craft: structured conversion copywriting, a working pricing interaction, accessible accordion/nav patterns, and polished micro-interactions — the kind of deliverable a freelance conversion-focused agency would charge $2,000–4,000 for.
